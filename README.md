## School Management Database

A SQL Server database project designed for a school management system. The database manages departments, teachers, students, courses, and student enrollments.

### Key Features

* Department and teacher management
* Teacher supervision relationships
* Course and department management
* Student and enrollment management
* Enrollment dates and student grades
* Relational database design with primary and foreign keys
* Data integrity using constraints and relationships

**Technologies:** SQL Server, T-SQL
